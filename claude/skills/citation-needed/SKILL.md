# Sourcing

Open the source before citing it. Search the web, then fetch the actual page with
`WebFetch`. Never describe a page you have not opened.

Trace every claim to a primary source, in this order:

1. Official docs or the spec
2. The source code itself
3. A reputable write-up
4. A blog, last

Match the version actually pinned in the lockfile or manifest, not "latest". Check the date
on everything and prefer the version currently in force.

Where sources disagree, say so and give the competing readings instead of silently picking
one.

Keep what a source says separate from inference drawn from it, and label the inference.
Never invent a citation, quotation, or statistic - "I couldn't find support for this" is a
good answer.
